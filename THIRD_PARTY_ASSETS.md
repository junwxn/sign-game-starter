# Temporary SgSL Sign Bank references

The game displays remote GIFs from the official
[Singapore Sign Language Sign Bank](https://blogs.ntu.edu.sg/sgslsignbank/)
as temporary teaching references. The GIF binaries are **not copied into this
repository**.

The Sign Bank footer states: “Copyright © 2026 The Singapore Association for
the Deaf. All rights reserved.” Linking and attribution here do not assert a
reuse licence. Obtain permission before a public release that depends on these
assets, or replace each `mediaUrl` and set `mediaType: 'video'` in
`src/signReferences.ts` when a team-owned recording is ready.

The landmark collection format did not save variant IDs. Entries with multiple
variants use the first/default variant except EAT, where the collected Flat-O
hand-to-mouth motion matches the bank's current `EATo` entry. These assumptions
still need confirmation by the person who recorded the training clips:
